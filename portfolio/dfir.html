Project Overview

This DFIR project is a multi-artifact, multi-host CTF investigation for a small financial services company showing clear signs of compromise across several Windows systems. Employees reported suspicious browser pop-ups, unexpected URLs opening automatically, and severe system slowness. The SOC then observed unusual network patterns, suspected Cobalt Strike beaconing, and suspicious SMB named pipe activity across multiple workstations.

The business impact goes beyond user annoyance: an internal SWIFT banking code appears to have been maliciously modified to reroute financial transactions, and the attacker may also be interested in the company’s internal cryptocurrency concept under development by the R&D team.

  • Evidence set: KAPE triage collections from 6 systems (ACC-01, ACC-02, ACC-03, ACC-04, ACC-07, ACC-10), including event logs, Sysmon, file system metadata, registry hives, Prefetch, browser history and more.
  • Core tools: KAPE, Hayabusa + Sigma rules, Eric Zimmerman's tools (Timeline Explorer, EvtxECmd, MFTECmd), Sysinternals Suite, Volatility, Wireshark, Autopsy / FTK Imager.
  • Techniques: multi-host timeline reconstruction, Windows artefact analysis (EVTX, Prefetch, MFT, registry), network traffic & beaconing investigation, SMB named pipe analysis, SWIFT manipulation & ransomware triage.
  • Objectives: trace initial compromise, lateral movement, credential dumping, persistence (e.g. JavaUpdater.exe), C2 infrastructure, ransomware execution and crypto-coin activity, and answer all stakeholder questions.
  • Deliverables: detailed DFIR report, IOCs, full attack timeline, blue-team recommendations, plus a 50–60 minute live demo of the investigation workflow.

Case Scenario – Small Financial Services Company

The investigation simulates a real enterprise incident handled by an internal DFIR team. After early user complaints about pop-ups and slow machines, defenders detect:

  • Unusual outbound traffic and likely Cobalt Strike beaconing from several workstations.
  • Suspicious SMB named pipe activity that may be associated with C2 channels and lateral movement.
  • Evidence that an internal SWIFT banking code was altered, potentially to redirect funds.
  • Artifacts suggesting the attacker probed or targeted the company’s in-house cryptocurrency concept.

My role in this project is to work through the collected artefacts and reconstruct the full kill chain across all six systems: identify patient zero, map every lateral move (from ACC-10, ACC-01, ACC-07, ACC-04, ACC-02), trace credential dumping and persistence mechanisms, and locate when and where ransomware was executed.

Scope, Evidence & Stakeholder Questions

The scope of this case covers six Windows endpoints (ACC-01, ACC-02, ACC-03, ACC-04, ACC-07, ACC-10) using KAPE triage outputs as the primary evidence source. From these artefacts I will:

  • Determine which host shows the first signs of compromise and how the attacker gained initial access.
  • Track lateral movement paths between the ACC-0X systems via RDP, SMB, and service creation.
  • Identify Cobalt Strike beacon IPs, ports, hostnames, and named pipes used for command-and-control.
  • Locate credential dumping activity, named pipes used concurrently, and resulting persistence mechanisms.
  • Analyze JavaUpdater.exe (timestomping, service creation, execution count across systems).
  • Reconstruct the PowerShell ransomware run (host, encryption function, cmdlets, ransom note, BTC address).
  • Confirm which SWIFT banking code was modified and how the attacker interacted with the crypto-coin project.
  • Summarize all IOCs (IPs, domains, hashes, file paths, pipe names) and map them to MITRE ATT&CK.

The final report follows a full DFIR structure: executive summary, scope & methodology, findings by artefact category, IOCs, attack timeline, conclusions, architectural and control recommendations, and contributions.

Key Techniques, Artefacts & Tools

  • Host triage & Windows artefacts: working from KAPE collections to examine event logs, Sysmon, MFT, Prefetch, registry hives, browser history and other NTFS artefacts across all six systems.
  • Hayabusa + Sigma & Timeline Explorer: generating a unified CSV timeline of Windows events, leveraging Sigma-based detections (including critical Cobalt Strike named pipe rules), then pivoting and visualizing activity in Timeline Explorer.
  • Malware, persistence & credential access: tracing suspicious binaries such as JavaUpdater.exe (creation time manipulation, service creation, execution count), credential dumping events, and use of named pipes for C2 and lateral movement.
  • Ransomware & SWIFT manipulation: identifying the system where the PowerShell ransomware ran, the encryption function and cmdlets used, ransom note artefacts, as well as the tampering with SWIFT codes and any crypto-coin references.
  • Blue-team recommendations & threat intel: mapping gaps to CIS/SANS controls, proposing concrete tools and architecture changes for detection and prevention, and correlating attacker IPs and infrastructure with public threat intelligence where possible.
